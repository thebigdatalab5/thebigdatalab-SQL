SQL Restaurant — Interactive SQL Playground

A playful UI that turns stage1.md concepts into a tiny game.

Welcome to the SQL Bistro

Rows are diners, columns are menu choices. Use the controls to place an order (build a query) and see what the chef returns.

  • Select which columns you want to see.
  • Filter with the doorman (WHERE).
  • Sort with the maître d' (ORDER BY) and only seat a few with LIMIT.
