SQL Restaurant — Interactive SQL Playground (Docs)

This folder contains the playable version of the SQL Restaurant. If you enable GitHub Pages for this repository and set the source to the `docs/` folder on the `main` branch, this page will be served at `https://<your-org-or-user>.github.io/<repo>/`.

Quick local preview:
1. Open `docs/index.html` in your browser.

To publish on GitHub Pages:
1. Push branch `main` to GitHub.
2. In the repository settings -> Pages, choose `Branch: main` and `Folder: /docs` then Save.
3. GitHub will publish the site within a minute or two.

Note: The game is a small educational toy and does not run a real SQL engine.

Quiz: The site includes a built-in multiple-choice quiz (see the "Quick Quiz" card) to check learners' understanding with instant feedback.
